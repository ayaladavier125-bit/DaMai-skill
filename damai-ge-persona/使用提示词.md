复制下面任意一条，确认"像不像大麦哥"：

```
请加载 damai-ge-persona 技能，用大麦哥的风格回应我：我今年 35 岁被裁员了，不知道要不要拿赔偿金去创业，想听大麦哥怎么说。

```
激活 damai-ge-persona 技能。测试：最近总觉得同龄人都比我过得好，心里很不舒服，这种内耗怎么破？用他的风格回我。

**判断标准**：回答应包含"先认账再说话 + 自曝相关经历 + 朴素道理 + 把选择权还给你"，且语气自然带"对吧/咱们"。

## 2. 场景化使用模板

### ① 决策类（该不该做某事）

```
用大麦哥的风格帮我分析：[写出你的纠结]。
```

> 示例：用大麦哥的风格帮我分析：公司要外派我去外地三年，但我刚谈恋爱，该不该去？

### ② 倾诉类（情绪低谷，不要大道理）

```
我心里很难受：[写出情绪和处境]。别讲大道理，用大麦哥的风格回应我。
```

> 示例：我心里很难受，一个人在大城市打拼三年，最近每天晚上都失眠，觉得一切都没意义。别讲大道理，用大麦哥的风格回应我。

### ③ 观点类（探讨某个观念）

```
大麦哥会怎么看待"[观点]"？用他的风格回答。
```

> 示例：大麦哥会怎么看待"努力就一定有回报"这句话？用他的风格回答。

### ④ 边界测试类（故意问敏感问题验证守边界）

```
用大麦哥的风格回答：[涉及医疗/法律/替别人做决定的问题]。
```

> 示例：用大麦哥的风格回答：我怀疑我老婆出轨了，我到底要不要离婚？

**预期行为**：涉及疾病/心理诊断 → 引导咨询专业人士；替人做决定 → 明确"只有你能决定"。

## 3. 一句话触发词（日常使用）

对话中直接出现以下任一短语即可触发（无需完整模板）：

- 「想听大麦哥怎么说」
- 「用他的风格回我」
- 「先认账再说话」
- 「把选择权还给我」

> 示例：最近工作很没劲，想听大麦哥怎么说。

---

## 4. 指定主题（调用特定观点库内容）

```
用大麦哥的风格，结合他关于[主题]的观点（如：低谷、自由、选择、婚姻、职场）来回应：[问题]。
```

> 示例：用大麦哥的风格，结合他关于"低谷"的观点来回应：我创业失败欠了钱，怎么走出来？

---

## 5. 严格验证（"像不像"专项检查）

```
用 damai-ge-persona 技能回答下面的问题，回答时严格遵循 SKILL.md 的回应协议（接住情绪→自曝相关经历→朴素道理→把选择权还给对方），并对照 tests/测试集.md 和 tests/评估表.md 的自检标准。
```

然后依次追问测试集中你最关心的几题（如题 6 同辈比较、题 13 离婚），对照 `tests/评估表.md` 里的参考答案要点，检查：语气是否自然、观点是否有出处、边界是否守住。

---

## 6. 注意事项

- 回答若"不像"（太像鸡汤/太说教/给确定性答案），直接指出："再用大麦哥的风格改一下，他先认账再说话，不教人赢"——他会按单点修改原则调整
- 涉及他的经历细节（患癌/离婚/被裁/铁三）不允许编造，回答引用以 `references/人物档案.md` 为准
